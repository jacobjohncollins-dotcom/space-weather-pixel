# Space Weather Pixel

Real-time space weather, shown as quirky pixel art. See [Plan.md](./Plan.md)
for the full project plan and chunked task breakdown.

## Dev

```
npm install
npm run dev
```

## Scripts

- `npm run dev` — start dev server
- `npm run build` — type-check and build for production
- `npm run lint` — oxlint
- `npm run format` — prettier --write
- `npm run format:check` — prettier --check
